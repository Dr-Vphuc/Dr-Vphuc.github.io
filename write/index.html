Soạn bài

Trang này cần một GitHub token để đăng bài lên repo.

  1. Vào Settings → Developer settings → Fine-grained tokens.
  2. Repository access: chọn Only select repositories → đúng repo blog này.
  3. Permissions: mục Contents đặt thành Read and write. Không cần quyền nào khác.
  4. Tạo xong, sao chép token rồi dán vào ô dưới.
